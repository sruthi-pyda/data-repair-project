## What this shows

1. **Where the gain comes from.** The ablation separates the evaluator change (V1→V2) from the learned corruption probability (V2→V3), because either alone would move the realised cost.
   - Entirely attributable to the learned q: breast_cancer k=1.5 outliers=on, smartfactory k=3 outliers=on, adult k=3 outliers=on. V2 is identical to V1 there, because with q = 1 the policy never abstains, so a conditional abstain charge has nothing to act on.
   - Unchanged by the branch (regression pin): breast_cancer k=3 outliers=on, smartfactory k=3 outliers=off.

2. **The two changes are not independent in principle, only in these runs.** V2 can only differ from V1 on cells where the old policy already abstained. Under every shipped cost config with q = 1, `C_abstain > C_human`, so ABSTAIN is unreachable (CLAUDE.md section 5.2) and V1 = V2 by construction. The evaluator change is therefore a *precondition* for the learned q to pay off, not an independent source of gain: without it, abstaining on a false alarm would still be charged `C_abstain` and the learned q would lose money instead of saving it.

3. **How q was obtained matters:**
   - **breast_cancer k=3 outliers=on**: raw detection_score as q reproduces the learned-q actions (cost 1615.0 vs 1615.0); dropping the smoothing prior changes nothing (cost 1615.0).
   - **breast_cancer k=1.5 outliers=on**: raw detection_score as q does NOT reproduce the learned-q actions (cost 2505.0 vs 1750.0); dropping the smoothing prior changes nothing (cost 1750.0).
   - **smartfactory k=3 outliers=off**: raw detection_score as q reproduces the learned-q actions (cost 14186.0 vs 14186.0); dropping the smoothing prior changes nothing (cost 14186.0).
   - **smartfactory k=3 outliers=on**: raw detection_score as q does NOT reproduce the learned-q actions (cost 85464.0 vs 14186.0); dropping the smoothing prior changes nothing (cost 14186.0).
   - **adult k=3 outliers=on**: raw detection_score as q does NOT reproduce the learned-q actions (cost 11658.0 vs 0.0); dropping the smoothing prior changes nothing (cost 0.0).

## What this does NOT show

- **Not a repair-quality result.** Every variant shares the same detections, the same mock repairs and the same calibrated p. Only the abstention arm moves. No number here says a cell was repaired better.
- **False negatives dominate and are priced at zero.** breast_cancer k=3 outliers=on: 239 undetected genuine corruptions; breast_cancer k=1.5 outliers=on: 234 undetected genuine corruptions; adult k=3 outliers=on: 1701 undetected genuine corruptions. No policy is charged for them, so a low total cost is a statement about the flagged cells only (docs/cost_semantics.md section 3).
- **Not a per-cell three-way choice.** `q*` is horizontal, so at a fixed q only two of the three arms are ever live for a single cell; all three appear across a population that mixes real errors with false alarms (docs/cost_semantics.md section 4).
- **Mock repairs, single split, one seed.** p comes from `src/repair/mock_repair.py`, not an LLM; calibration uses one 70/30 split at seed 42 with no confidence interval (CLAUDE.md section 5.4).
- **The baselines never abstain,** so they are unaffected by the semantics question this ablation is about; they are context for the cost scale, not a test of it.
- **Soft leakage is unchanged.** `DatasetProfile` is still built from `clean_df` (CLAUDE.md section 3), so detector fences and imputation statistics carry population-level clean knowledge in every variant alike.
