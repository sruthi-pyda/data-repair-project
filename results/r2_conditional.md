# R2 — Conditional-model error detection: measured results

_Generated by `experiments/r2_conditional.py`. Every number below was produced by that script; none is written by hand._

## Setup

- seed: `42`
- split: seeded row split, stratified on "row has any corrupted cell", 70% fit / 30% evaluate; **all numbers are eval-only**
- detector: `ConditionalDetector`, `max_iter=100`, `profile=None` (fully self-supervised; nothing clean-derived enters the detector)
- labels: `ValueComparator` (tolerance-based) on clean vs dirty, post-prediction only
- metric backend: `src.detection_eval.evaluate_scores (cross-checked vs sklearn)`
- bootstrap resamples for the PR-AUC CI: 100
- total runtime: 243.5s

Modes:

| mode | score | role |
|---|---|---|
| `full` | `1 - P(value \| rest of row)` | the method |
| `marginal` | `1 - P(value)` | **the control** — if `full` does not beat this, conditioning is not what helps |
| `ratio` | `sigmoid(log P(value) - log P(value \| row))` | isolates "marginally common, conditionally rare" |

One fit per dataset, scored in all three modes, so the modes share byte-identical fitted models.

## 4. Residual-tail ablation (`mode="full"`, all eval cells)

The numeric branch turns a standardised residual into a plausibility through a tail function. `gaussian` is the textbook choice but its score `1 - tail` rounds to exactly 1.0 once |z| exceeds about 8.3, collapsing every strong numeric outlier onto one score; PR-AUC is a pure ranking metric, so that loses real resolution. `cauchy` decays like 1/|z| and never saturates. The default is `cauchy` **because of the numbers below**, not by preference. Same fitted models in both rows -- only the scoring arithmetic differs.
